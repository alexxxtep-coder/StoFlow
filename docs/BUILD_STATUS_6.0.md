# STO.Flow 6.0 — статус сборки и границы проверки

## Реализовано в текущей итерации

- Next.js App Router + React + TypeScript + Supabase SSR/PostgreSQL/RLS.
- Основные рабочие зоны: Сегодня, Работа, CRM, Календарь, Задачи/WIP, Parts.Finder, Финансы, Аналитика, Управление и настройки.
- Атомарное создание обращения, строк заказ-наряда, платежа и распределения.
- История статусов, переходы, реестр завершённых заказов и проверка остатка.
- DB guards для закрытых заказов, изменения цены/количества после оплат, неполных финансовых строк, задач/заявок и повторного создания workspace.
- Миграция 0004: проверки предложения/заявки перед закупкой, защита прямой вставки в `purchases`, блокировка прямого изменения/удаления до реализации процесса приёмки.
- Единая timezone-логика IANA для записи/отображения дат и валидация timezone в настройках.
- Проверка точности денежных значений и количества.
- Ролевые запросы аналитики и UI-формы согласованы с матрицей RLS в известных сценариях.
